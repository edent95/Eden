# 实战手册

这份参考只在三类情况加载：

- 用户要按职场、合作、谈判、暧昧关系分别分析
- 用户要把某段对话拆成权力信号
- 用户要设计“不撕破脸但不吃亏”的回复

## 四步拆局面

面对复杂对话，优先按这四步判断：

1. 先看目标。
   对方想要资源、时间、责任转移、情绪满足，还是位置优势。
2. 再看筹码。
   谁有决定权，谁有替代选项，谁更怕关系破裂，谁更急。
3. 再看动作。
   对方是在试探、施压、拖延、画饼、甩锅、借关系压价，还是想把你推到前台。
4. 最后看代价。
   你如果答应，会失去什么；你如果拒绝，会失去什么；哪一种更可控。

## 按场景拆

### 职场

优先看：
- 资源归谁
- 责任落谁
- 信息是否对称
- 关键节点有没有留痕

高频信号：
- “先做出来再说”通常是在让你先背投入
- “这是大家的共识”通常是在稀释个人责任
- “你能力强，辛苦你多扛一点”可能是在用赞美换额外付出

默认建议：
- 口头任务转文字确认
- 大任务拆交付边界
- 先问优先级和授权范围

### 合作

优先看：
- 收益怎么分
- 成本谁先出
- 风险谁来扛
- 退出机制有没有写清楚

高频信号：
- 只谈愿景，不谈分工
- 只谈情义，不谈合同
- 只催你投入，不给对等承诺

默认建议：
- 先小单试合作
- 关键条件写下来
- 不在模糊承诺上提前投入不可逆资源

### 谈判

优先看：
- 对方急不急
- 你有没有替代方案
- 对方压价靠的是情绪，还是现实筹码

高频信号：
- “别人都能接受这个条件”是在制造从众压力
- “这次真的是特例”常常是在压缩你的反应时间
- “我们以后有很多机会合作”如果没有当前绑定条件，价值有限

默认建议：
- 不对临场施压立即表态
- 先确认条件，再确认期限
- 能换条件就别只降价

### 暧昧关系

优先看：
- 对方给的是情绪价值，还是稳定投入
- 对方是否在关键问题上持续模糊
- 你的期待和对方的投入是否匹配

高频信号：
- 平时很会说，关键时刻总缺席
- 口头在乎很多，实际安排很少
- 只在自己需要陪伴时出现

默认建议：
- 看连续行为，不看单次表达
- 看是否愿意承担明确关系带来的代价
- 不替对方补完他没给出的承诺

## 把对话拆成权力信号

用户贴来原话时，优先标出下面几类信号：

### 1. 试探信号

常见形式：
- “你最近应该没那么忙吧”
- “这个对你来说应该不难”

含义：
- 先测试你会不会主动让步

### 2. 责任转移信号

常见形式：
- “你先帮忙推进一下”
- “你比较懂，你来定吧”

含义：
- 好处未必给你，责任先挂你身上

### 3. 关系绑架信号

常见形式：
- “我们这么熟了，这点事不至于吧”
- “你这样就有点见外了”

含义：
- 用关系感压低交易成本

### 4. 时间施压信号

常见形式：
- “最好今天就定”
- “现在不决定就来不及了”

含义：
- 压缩你思考和议价空间

## “不撕破脸但不吃亏”的回复框架

### 框架一：先接，再卡条件

适合：对方客气试探、借关系压价

句式：
- “我理解你的意思，不过这件事我要按 X 的边界来处理。”
- “关系是关系，这件事落地还是要按条件说清楚。”

### 框架二：先留白，再要确认

适合：对方想把你推上责任位

句式：
- “我先不急着答应，得先把范围和责任口径对齐。”
- “可以讨论，但我需要你先把目标、资源和时间点说清楚。”

### 框架三：先体面，再拒绝

适合：不想撕破脸，但必须止损

句式：
- “我知道你是希望事情快点推进，但这个方式我这边接不了。”
- “这件事我先不参与，免得后面边界不清反而更难做。”

## 输出时的默认提醒

如果证据不足，可以明确加一句：

- “按你给的信息看，这是高概率判断，不是定论。”
- “我先按最常见的利益结构帮你拆，具体还要看对方后续动作。”
