## 2026-11-02 — 首页改成 Apple Services 式排法：Pukimon 实时对战演示做成大横幅，下面一排带标题的作品卡片；手机和 iPad 改成手指滑动

### [E-2026-11-02-201643-d67f] 首页改成 Apple Services 式排法：Pukimon 实时对战演示做成大横幅，下面一排带标题的作品卡片；手机和 iPad 改成手指滑动

- type: feat
- scope: App.tsx（首页区块顺序）、components/HomePukimonGame.tsx、styles/pages/pukimon.css（首页 #pukimon）、app/home-collage.tsx、styles/pages/home.css（首页 #work）
- impact: 用户反馈首页视频横幅在手机和 iPad 上有 bug，并要求照 apple.com/my/services 的排法：一个大的 Pukimon 对战画面，下面才是滚动的横幅。现在首页顺序是 hero → #pukimon（只有「赤红 vs 青绿」三回合实时演出，撑满宽度，不配任何文字——用户先看过一版带标题、介绍和「了解更多」的，要求全部拿掉；电脑上最多一屏高、平板和手机贴齐两边）→ #work 一排作品卡片（每张下面写名字和分类：产品 / 文章 / 游戏 / 互动实验 / 影片 / 摄影）→ 暂停键 → About。原来两排左右漂移的拼贴变成一排；电脑上慢慢漂移、鼠标移上去会停；手机、iPad 和触屏不漂移，改成原生横向滑动加吸附，不再碰 iOS Safari 算漂移动画出错的问题；手机原来的 4 栏小格子（10 张最后一排剩 2 张）也没了。
- changed: App.tsx 把 HomePukimonGame 挪到 #work 拼贴前面。HomePukimonGame 去掉全部文案（标题、介绍、「Pukimon 介绍页」链接、三回合说明）和外框面板（KaleidoFrame），只剩全宽舞台，section 用 aria-label 说明内容；首页因此不再有链到 /pukimon 的文字链接，只剩拼贴里的 Pukimon 卡片。pukimon.css 首页 #pukimon 一段重写。home-collage.tsx 每项加 kind，删掉 ctaLabel；HomeCollageCard / HomeCollageRow 换成 HomeShelfItem / HomeShelfRow（一排、只向左漂移）；外层 .eden-showcase 带暂停键，暂停时 .is-paused 停掉漂移，HomeCollageVideo 的播放判断也因 .is-paused 停掉视频。home.css 删掉悬停浮现按钮 .eden-collage-reveal / .eden-collage-cta、第二排向右漂移、手机 4 栏格子，新增 .eden-shelf-*、.eden-showcase-pause 与 (hover:none)/(pointer:coarse)/(max-width:1024px) 的滑动版。
- ripples: (1) 首页 #pukimon 舞台是跨网域 iframe，要能点「开声音」，以后要加字只能放在舞台外面，不能像视频横幅那样压字；用户明确要这块不配文字，加回来前先问；/pukimon 页顶部用的是同一个 PukimonShowdownFrame，样式不受这次影响。(2) 新增拼贴项必须带 kind，否则类型检查不过。(3) 小于等于 1024px 或触屏一律不漂移，复制的那一份卡片用 CSS 隐藏；以后改漂移逻辑，别让平板重新走 translateX 动画（原因见 HomeShelfRow 注释）。(4) 拼贴里的 Pukimon mp4 卡片保留，和上面的实时演出同时出现；用户嫌重复再拿掉。
- verified: npm run check；本地预览用 Chrome 里三个 iframe 实测 1440 / 820 / 390px：舞台 1429×804、820×461、390×219；820 与 390 宽度卡片不漂移、可横向滑动、复制的一份隐藏。
