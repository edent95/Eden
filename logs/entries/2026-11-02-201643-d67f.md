## 2026-11-02 — 首页拼贴改版：Pukimon 对战视频做成整幅大横幅，下面一排带标题的卡片；手机和 iPad 改成手指滑动

### [E-2026-11-02-201643-d67f] 首页拼贴改版：Pukimon 对战视频做成整幅大横幅，下面一排带标题的卡片；手机和 iPad 改成手指滑动

- type: feat
- scope: app/home-collage.tsx（HomeCollage）、styles/pages/home.css（首页 #work 区块）
- impact: 首页原来是两排左右漂移的视频拼贴，手机是 4 栏小格子（10 张最后一排只剩 2 张），iPad 走电脑版的漂移动画，用户反馈手机和 iPad 上横幅有 bug。现在照 Apple Services 页的排法：最上面是 Pukimon 对战视频整幅横幅（左下角「Pukimon · 实时擂台」、一句标题、「立即开玩」跳到首页 #pukimon 演示、「了解更多」去 /pukimon），下面一排其余 9 张卡片，卡片下面写标题和分类（产品 / 文章 / 游戏 / 互动实验 / 影片 / 摄影），再下面一个暂停键。电脑上这排卡片慢慢漂移，鼠标移上去会停；手机、iPad 和所有触屏不漂移，改成原生横向滑动加吸附，不再碰 iOS Safari 算漂移动画出错的问题。横幅比例：电脑 16:9（最高 86vh），平板 4:3，手机 4:5。
- changed: home-collage.tsx 每项加 kind（分类说明），删掉不再用的 ctaLabel；HomeCollageCard / HomeCollageRow 换成 HomeShelfItem / HomeShelfRow（只剩一排、只向左漂移）；新增 HomeFeatureBanner；HomeCollage 外层 .eden-showcase 带暂停键，暂停时 .is-paused 停掉漂移，HomeCollageVideo 的播放判断也会因为 .is-paused 停掉所有视频（含大横幅）。home.css 删掉悬停浮现按钮 .eden-collage-reveal / .eden-collage-cta、第二排向右漂移、手机 4 栏格子，新增 .eden-feature*、.eden-shelf-*、.eden-showcase-pause，以及 (hover:none)/(pointer:coarse)/(max-width:1024px) 的滑动版；减少动效时大横幅视频也隐藏。
- ripples: (1) 首页大横幅放哪一项由 home-collage.tsx 的 FEATURE_TITLE 决定（现在是 'Pukimon'），标题文案写死在 HomeFeatureBanner 里，换主打项要一起改；「立即开玩」写死跳 #pukimon，依赖 HomePukimonGame 的 section id="pukimon"。(2) 新增拼贴项必须带 kind，否则类型检查不过。(3) 小于等于 1024px 或触屏一律不漂移，复制的那一份卡片在这些宽度用 CSS 隐藏；以后改漂移逻辑，别让平板重新走 translateX 动画（iOS Safari 的问题见 HomeShelfRow 注释）。(4) Pukimon 横幅视频是同人素材（红帽训练家），原本就在首页拼贴里公开，这次只是放大，没有新增素材。
- verified: npm run check；本地预览在 Chrome 实测：1680px 宽横幅 16:9 在播、下面一排漂移；390px（手机）与 820px（iPad）横幅 4:5 / 4:3、卡片不漂移可横向滑动、复制的一份隐藏。
