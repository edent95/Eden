## 2026-10-28 — 悬浮留言光球：外圈光晕不再被裁成方形，改成自然的圆形光晕；打开时不再显示 X

### [E-2026-10-28-211204-5b7c] 悬浮留言光球：外圈光晕不再被裁成方形，改成自然的圆形光晕；打开时不再显示 X

- type: fix
- scope: components/HomeLiveChat.tsx, styles/pages/live-chat.css（全站悬浮留言光球 .eden-chat-orb）
- impact: 全站右下角的留言光球，外圈光晕原本会被裁成四方形（用户反馈）；现在是一圈柔和、慢慢呼吸的圆形光晕，悬停时呼吸加快。打开留言板时光球保持原样，不再叠一个白色 X，也不再变暗；关闭仍靠再点一下光球或按 Esc。
- changed: 三个颜色团和玻璃高光移进新的内层 .eden-chat-orb-core（clip-path: circle 加 overflow 裁圆，带模糊和动画的层不会再漏到方形角落）；原先 button 上的彩色 box-shadow 换成 .eden-chat-orb::before 的圆形径向渐变光晕（模糊 6px，4.8s 呼吸动画 eden-chat-orb-flare，减少动效时关掉）；删掉 .eden-chat-orb-close 及其 CSS、打开时变暗的规则。
- ripples: (1) 光球的光晕现在是 ::before（z-index:-1，靠 button 的 isolation 留在光球后面），以后再给 .eden-chat-orb 加 overflow:hidden 或 clip-path 会把光晕裁掉，裁圆只能加在 .eden-chat-orb-core 上。(2) 打开状态不再有视觉上的「关闭」提示，只剩 aria-label 切换成「关闭留言板」；如果以后有人反馈不知道怎么关，再考虑在面板头部加关闭键，而不是放回光球上的 X。
- verified: npm run check；本地预览任意页面右下角光球是圆形光晕、点开后无 X。
- keywords: live chat, 悬浮留言, 光球, orb, glow, 光晕, box-shadow, clip-path, close X
