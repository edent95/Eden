## 2026-09-29 — 美术化 Notes 的顶部菜单融入页面：共享层新增 `.menu-blend` 变体

### [E-2026-09-29-194839-2064] 美术化 Notes 的顶部菜单融入页面：共享层新增 `.menu-blend` 变体

- type: style
- scope: 美术化（grimoire）的 Notes 文章与 Wiki note 顶部菜单与阅读条；`styles/shared.css`、`pages/ContentPages.tsx`、`styles/pages/notes-storyboard.css`、`AGENTS.md`
- impact: 用户截图指出顶部菜单「很突兀跟背景不融合」：它原是一条只有内容区宽、近乎不透明的浅色长条，把颗粒底纹、黄金网格和星点整条切断。现在在页面顶部时菜单完全透明，直接浮在封面画面上；往下滚时底色随滚动距离（0 → 260px）渐显，铺满整个视口宽度，带 16px 背景模糊与和页面一致的颗粒纹理（深色模式不叠颗粒以免抬亮）；下方阅读条用同一种全宽模糊表面，与菜单连成一体。
- changed: `styles/shared.css` 新增 `.menu-blend`（覆盖共享菜单的背景 / 边线 / 阴影 / backdrop-filter，改由全宽 `::before` 提供底色 + 模糊 + 发丝线、`::after` 提供颗粒），透明度 `--menu-blend-a = clamp(0, --nd-scroll / 260, 1)`，`--nd-scroll` 未设置时视为不透明；两个 notes-topbar 在 grimoire 时加 `menu-blend`；notes-storyboard.css 给 grimoire 设 `--menu-texture` 并把阅读条改为全宽模糊表面；AGENTS.md 菜单规则写明此变体由共享层拥有、页面只能加类名。
- ripples: 菜单本身不能再有 `backdrop-filter` 或 `clip-path`——两者都会让菜单成为 backdrop root，全宽 `::before` 就只能模糊菜单内部（第一版用 box-shadow 铺全宽时，内容区外完全没有模糊）。依赖 `useNotesDepth` 写入的 `--nd-scroll`：reduced motion 下 hook 不运行，变量缺省为 9999 → 菜单直接不透明，不会出现透明菜单压在正文上。其它页面若要同样效果，只需加 `menu-blend` 并提供 `--nd-scroll`。
- verified: `npm run check` 全绿；CDP 截图 localhost:4180 `/zh/notes/iraq-war-evidence-map`：顶部状态菜单背景计算值为完全透明；滚动 1400px 后 `::before` 的 backdrop-filter 为 blur(16px)、left 为 −1440px（铺满视口），菜单与阅读条连成全宽表面，放大确认其下文字被模糊。
