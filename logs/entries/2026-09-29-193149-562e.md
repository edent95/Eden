### [E-2026-09-29-193149-562e] Notes 页边徽章改成精确绘制的 SVG 数学纹章（公式美学）

- type: style + feature
- scope: 全部美术化 Notes 的页边徽章（宽屏 ≥1280px）；新增 `components/css-art/notes-math-emblems.tsx`、`components/css-art/notes-math-geometry.ts`（生成数据）、`scripts/css-art/notes-emblems.py`（生成器）、`styles/css-art/notes-emblems.css`；改 `pages/ContentPages.tsx`、`styles/pages/notes-storyboard.css`、`components/css-art/index.tsx`、`css-art.registry.ts`、`index.css`、`AGENTS.md`
- impact: 用户附四张截图指出页边徽章「没有数学公式美学」：旧徽章只是把分镜画面裁成圆形、调淡，线条粗、主体被裁歪。现在每枚是一张精确绘制的数学图版：曼德博集合的 7 阶双纽线 |zₙ(c)| = 2（numpy 网格 + marching squares 求等值线，逐阶嵌套逼近边界，内部排线填充）、斐波那契黄金矩形细分与四分之一圆弧 + 连续对数螺旋 r = a·e^(bθ)、悬链曲面 r = c·cosh(z/c) 的经纬线框（前后分深浅）、8 条不同参数的悬链线族、罗宾逊三角形 4 次细分得到的彭罗斯 P3 镶嵌、233 颗种子叶序与其 21 / 34 条斜列线、7 条相位递增的李萨如曲线族；底下是 φ 比例的同心构造圆与 30° 放射线，外圈沿圆形路径刻公式并慢转。读到该节时曲线用 pathLength=1 逐条描出、种子逐颗弹出、彭罗斯从中心旋转长出，并有笔尖点沿主曲线移动。徽章加大到 176px，带投影与微倾斜。
- changed: `ng-medal` 内由 `NotesStoryFrame` 改为 `NotesMathEmblem`（essay 与 Wiki note 两处）；几何由生成器写入固定 TS 数据（约 50KB，去掉了用不到的彭罗斯边线数据）；新 registry 条目 `notes-math-emblems`。
- ripples: 几何数据只能用 `python3 scripts/css-art/notes-emblems.py` 重新生成，不要手改 `notes-math-geometry.ts`。彭罗斯细分 5 次在 176px 里太碎，4 次才看得出五重对称。SVG 的 pattern / clipPath / textPath id 用 `React.useId()` 去掉非字母数字字符，避免同页多枚纹章 id 冲突与 url(#…) 解析问题。笔尖点用 SMIL `animateMotion`，只在该节被阅读时渲染；reduced motion 下隐藏笔尖并停止所有描线动画。
- verified: `npm run check` 全绿；`verify:css` 17 个家族通过；CDP 在 localhost:4180 逐节滚动截图 7 种纹章（浅色 5 枚、深色 5 枚），修正彭罗斯过碎；确认生成器重构后输出逐字节一致。
