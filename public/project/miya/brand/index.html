MiYa

用大白话看懂你的健康数据。一份只在你自己的 iPhone 上生成的 Apple 健康报告。视觉是一张钞票凹版:米纸、排线、双线框、扭索纹,中间一颗品牌红的心。

看得懂一个数字,一句大白话。
只在本机不注册,不上传,没有服务器。
不是诊断只和你自己的平时比。

怎么说话

一句大白话,讲完就停。每个数字下面最多一句解读,先说结论,再给一个日常比方。术语只留一句解释,放进「?」气泡里。

场景这样写不这样写
指标解释静坐时每分钟心跳,越低越省力。静息心率(RHR)是衡量心血管健康的重要指标……
变化心脏比之前每分钟少跳 6 下,干活更省力了。您的静息心率呈显著下降趋势。
分数0–100,和你的平时比。基于先进算法的综合健康评分
页标题健康 / 心率 / 恢复 / 活动 / 运动 / 数据我的健康数据总览中心

基本规矩

  • 称呼用「你」,不用「您」。英文用 you,句子短,不用感叹号。
  • 不用 emoji。原本放 emoji 的地方,一律换成凹版图标。
  • 数字与单位之间空一格:62 次/分、48 ms、近 90 天。
  • 中英两套文案同步改;英文版里不出现中文。

健康边界是硬规矩

分数一律说成「和你的平时比」的相对估算,不说正常或异常。没有睡眠数据时直说无法判断。绝不写诊断,不出现「心脏不好」「可能患有」。需要提醒时,给出能做的事:

如有胸痛、明显气短、头晕或心悸,请停止运动并及时就医。

隐私要说得具体

用能核对的事实,不用形容词。不写「军工级加密」「绝对安全」。

所有计算都在你的 iPhone 上完成。不注册账号,没有服务器,没有统计分析,没有广告。只读取「健康」里的数据,从不写入。

色彩

界面以中性色为主,品牌红一屏只出现在一两处。凹版件(图标、横幅、纹章、App 图标)有自己的一套墨色:浅色是墨绿配米纸,深色是古铜金配近黑。

用色规则

  • 页面用 page 打底,卡片用 surface。卡片不画边框,靠 shadow 和页面分开。
  • 品牌红 accent 只给主按钮、选中态、焦点圈和首页那颗心。选中项的底用 accent-soft。
  • 状态色只画图形(点、条、圆环),每个状态都配一个词或箭头,不能只靠红绿区分。
  • 金箔每个凹版件只点一处:指针、落脚点、高亮日、心上的那粒圆点。
  • 两处对比度偏低,目前保留原值:浅色主题下 ink-muted 在白底上只有 3.2:1,只给可有可无的注脚;白字放在 accent 上是 3.8:1,所以主按钮文字用 13px 粗体以上。

标志

三枚标志都来自同一条心形线。用原件,不要重画;心形不用通用的 ♥ 字符或第三方图标代替。

App 图标

深色底,φ 刻度环、扭索纹、排线填面的品牌红心,一粒金箔。圆角由系统裁切,不要自己加框或阴影。

手表图标

同一颗心的手表版,系统裁成圆形。改任何一处图标,iPhone、手表、小组件三个 target 的版本号一起改。

心形标

米纸底、双线框、品牌红心形。浏览器标签和 32px 以下的场景用它。深浅主题都用同一份。

不拉伸
不旋转
不加发光或阴影
不换色
不放进低对比背景

图标与插画

图标是纯 CSS 画的凹版小件,1:1 圆角框:米纸版面、双线框、慢转的扭索纹环、主体(排线填面、双线描边、一点金箔、一种色洗),再加一个小动效。每个图标都有一个数学母题。

心heart

心形线 x = 16 sin³t

脚印steps

鞋底 1 : φ 的黄金椭圆,两脚落在 38.2% / 61.8%

勋章medal

φ 五芒星,对角线 : 边 = φ

罗盘compass

φ 刻度环,半径 23.6 → 38.2

旅程traveler

黄金螺旋,光点从极点向外走

血氧drop

正方形转 45°,高 : 宽 = √2 : 1

呼吸breath

同一个圆切两段弧,按 38.2% / 61.8% 开合

表盘gauge

开口 ±38.2° 的 φ 刻度弧

阶梯stairs

三级踏步按 φ 递进

  • 新图标先找母题,再画。焦点放在黄金点,颜色只取凹版三色和一种系列色作色洗。
  • 尺寸只改 --gi-size;小于 48px 时去掉刻度环与构造线,线条加粗。

动效

默认安静。一次只有一个主动作,其余是很慢的呼吸或旋转。

  • 缓动统一 cubic-bezier(.23,1,.32,1):先快后稳。
  • 主动作跟数据走:纹章指针扫到电量的位置、地图航迹进场。只动 transform 和 opacity。
  • 扭索纹慢转一圈 60–240 秒。本页右上那枚纹章转一圈 120 秒。
  • 系统打开「减少动态效果」时,一切静止。
