# Raw Sources

Raw source material belongs here before it is synthesized into `wiki/`.

Rules:

- Treat existing raw files as immutable evidence.
- Add corrections or newer sources as new files; do not silently rewrite an old source.
- Never store credentials, private customer data, or material that cannot be committed publicly.
- Public full-text HTML currently served from `public/` remains in place for URL compatibility. Its corresponding Wiki/Notes metadata should identify it through `originalSource`.
